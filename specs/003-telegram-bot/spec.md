# Спецификация (Feature 003: Telegram Бот)

## 1. Суть фичи
Пользователь (владелец) отправляет CSV-файл с банковской выпиской в своего личного Telegram-бота. Бот принимает файл, передает его в наш парсер (Feature 001), затем отправляет транзакции в нейросеть (Feature 002) и возвращает пользователю текстовый отчет о том, сколько денег и на какие категории было потрачено.

## 2. Требования
- Использовать библиотеку `aiogram` (версии 3.x).
- Бот должен быть **приватным**. Он должен реагировать только на сообщения от твоего Telegram ID (остальных игнорировать).
- **Вход**: Документ (CSV файл).
- **Процесс**: 
  1. Скачать файл во временную папку.
  2. Вызвать `parse_csv(file_path)`.
  3. Вызвать `categorize_transactions(transactions)`.
  4. Подсчитать сумму по каждой категории.
- **Выход**: Текстовое сообщение с результатами (например, "🍕 Фастфуд: 1500 руб\n🛴 Самокаты: 500 руб").

## 3. Технические детали
1. **Зависимости**: `aiogram`.
2. **Переменные окружения (`.env`)**:
   - `BOT_TOKEN` — токен, полученный от BotFather.
   - `OWNER_ID` — твой числовой ID в Telegram (чтобы защитить бота от чужих).
3. **Архитектура**:
   - `src/bot/handlers.py`: логика обработки команд (`/start`) и приема файлов.
   - `src/bot/main.py`: точка входа для запуска бота в режиме Long Polling (для локальной разработки это проще, чем вебхуки).

## 4. Тестирование (TDD)
- Напишем unit-тесты для функции подсчета статистики (группировка сумм по категориям).
- Интеграционный тест самого бота (через мокирование Telegram API) писать сложно и долго для MVP, поэтому логику обработки файлов вынесем в отдельную функцию-сервис, которую легко протестировать классическим `pytest`.
