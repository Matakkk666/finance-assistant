# План реализации (Feature 003: Telegram Bot)

## Архитектура
1. **Зависимости**: Добавим `aiogram` в проект.
2. **Аналитика (`src/services/analytics.py`)**: 
   - Чистая Python-функция, которая принимает список транзакций и группирует суммы по категориям. (Легко тестируется через pytest).
3. **Бот (`src/bot/handlers.py` и `src/bot/main.py`)**:
   - `main.py`: Инициализация бота, чтение `.env`, запуск поллинга.
   - `handlers.py`: 
     - Обработка команды `/start`.
     - Middleware или проверка `if message.from_user.id != OWNER_ID: return`.
     - Обработка приема документа (скачивание файла -> парсинг -> ИИ -> аналитика -> отправка ответа).
