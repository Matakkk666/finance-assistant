# План реализации: 008-bank-oauth-connect

## Этап 1: Backend и База данных (TDD)
1. **Модель БД:**
   - В `src/models/db.py` добавить модель `BankConnectionDB` (таблица `bank_connections`).
   - Настроить индексы и методы сохранения/поиска связей.
2. **API Эндпоинты:**
   - В `src/api/routes.py`:
     - `GET /api/banks`
     - `POST /api/banks/connect`
     - `GET /api/banks/auth-screen` (стилизованный HTML-экран подтверждения банка)
     - `GET /api/banks/callback`
     - `POST /api/banks/sync`
     - `POST /api/banks/disconnect`
3. **TDD Тесты API:**
   - Написать тесты в `tests/test_api_banks.py`:
     - Проверка получения списка банков со статусами.
     - Проверка прохождения OAuth-цепочки (connect -> callback -> статус `connected`).
     - Проверка вызова синхронизации из API для подключенного банка.

## Этап 2: Frontend (Telegram Mini App)
4. **Вкладка и карточки банков:**
   - В `frontend/src/App.tsx`:
     - Добавить таб `'banks'` в состояние `activeTab`.
     - Добавить кнопку **«Банки»** в нижнюю навигационную панель с иконкой `Landmark`.
     - Отрендерить красивый экран управления банками:
       - Карточки Сбера, Т-Банка, МКБ.
       - Бейджи статусов (`Подключен` / `Не подключен`).
       - Кнопки `[Подключить банк]` и `[Синхронизировать]`.
5. **Интерактивный поток авторизации:**
   - При нажатии `[Подключить]` открывать всплывающее окно / переход на экран подтверждения авторизации банка.
   - По возвращении автоматически обновлять список подключенных банков и баланс.

## Этап 3: Проверка и тестирование
6. Прогнать сборку фронтенда `npm run build` (TypeScript checks).
7. Прогнать тесты бэкенда `pytest` и линтер `flake8`.
