# Задачи для Субагента (TDD)

Привет! Твоя задача — реализовать Text-to-SQL движок для финансового ассистента.

- [ ] **Задача 1: Безопасность и Валидация**
  - В `src/services/chat.py` напиши функцию `validate_sql(sql: str) -> bool`.
  - Она должна возвращать `False`, если в строке есть слова (независимо от регистра): `DROP`, `DELETE`, `UPDATE`, `INSERT`, `ALTER`, `TRUNCATE`.
  - Напиши тесты в `tests/test_chat.py` на эту функцию (Red -> Green).

- [ ] **Задача 2: Генерация SQL (Моки)**
  - В `src/services/chat.py` напиши функцию `generate_sql(question: str, owner_id: int) -> str`.
  - Она должна использовать клиент Gemini (`src.services.llm`) для генерации SQL. Обязательно передай в промпт схему таблицы и требование фильтровать по `owner_id={owner_id}`.
  - Напиши тест в `tests/test_chat.py`, замокав ответ Gemini (чтобы он возвращал фейковый SQL).

- [ ] **Задача 3: Выполнение SQL и ответ**
  - Реализуй главную функцию `process_user_question(question: str, owner_id: int, db_session) -> str`.
  - Логика:
    1. `sql = generate_sql(question, owner_id)`
    2. Если не прошел валидацию -> вернуть "Извините, не могу выполнить этот запрос."
    3. Выполнить SQL через `db_session.execute(text(sql))` (импортируй `text` из `sqlalchemy`).
    4. Отправить результат SQL и исходный вопрос обратно в Gemini для получения человеческого ответа.
  - Напиши мок-тест на всю цепочку.

- [ ] **Задача 4: Интеграция в Бота**
  - В `src/bot/handlers.py` добавь `@dp.message(F.text)` хэндлер, который будет ловить обычные текстовые сообщения от пользователя, передавать их в `process_user_question` (получив сессию БД) и отправлять ответ.
  - Убедись, что все тесты проходят и `flake8` зелёный.
