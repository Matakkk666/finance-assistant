# План реализации (Text-to-SQL)

1. **Сервис Chat Engine:** Создать `src/services/chat.py`.
2. **Промпт генерации SQL:** Написать системный промпт для Gemini, описывающий схему таблицы `transactions` (`id, owner_id, date, amount, description, category`) и требующий вернуть *только* валидный SQL-запрос PostgreSQL.
3. **Безопасность (Validation):** Написать функцию проверки сгенерированного SQL (простая проверка на отсутствие слов `DROP`, `DELETE`, `UPDATE`, `INSERT` и обязательное наличие `owner_id`).
4. **Выполнение SQL:** Написать функцию, которая берет строку SQL и выполняет ее через `session.execute(text(sql))` в SQLAlchemy.
5. **Генерация ответа:** Написать второй вызов Gemini, который принимает вопрос пользователя и результат SQL, и генерирует дружелюбный текст ответа.
6. **Telegram Handler:** В `src/bot/handlers.py` добавить хэндлер для всех текстовых сообщений, который вызывает `chat_engine(user_id, text)` и отправляет результат пользователю.
7. **TDD:** Написать тесты с использованием моков Gemini API и in-memory SQLite (убедиться, что SQLite сможет проглотить сгенерированный SQL, либо мокать саму БД).
