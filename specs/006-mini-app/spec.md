# Спецификация: 006-mini-app (Telegram Web App Dashboard)

## 1. Контекст
Пользователю неудобно анализировать свои финансы исключительно через текст в чате. Ему нужна визуализация: красивые графики, список транзакций и общая статистика. Для этого мы создаем Telegram Mini App (TMA).

## 2. Архитектура решения
Разделяем проект на Backend (REST API) и Frontend (React SPA).
- **Backend (FastAPI):**
  - Добавляем маршруты `/api/stats` (общая статистика и данные для графика) и `/api/transactions` (список транзакций).
  - Настраиваем раздачу статических файлов (фронтенда) через FastAPI.
  - Настраиваем CORS для локальной разработки.
- **Frontend (React + Vite):**
  - Инициализируем проект в папке `frontend/`.
  - Используем Tailwind CSS для верстки, чтобы дашборд выглядел современно.
  - Используем Recharts для отрисовки круговой диаграммы (Donut Chart).
  - Интегрируем `@twa-dev/sdk` для связи с Telegram (использование цветов темы Telegram, кнопка закрытия).

## 3. Требования к UI/UX
- Темная и Светлая тема автоматически подстраиваются под тему пользователя в Telegram.
- Сверху: Крупным шрифтом "Всего потрачено".
- По центру: Круговая диаграмма (расходы по категориям).
- Снизу: Скроллируемый список последних транзакций.
- Вибрация (Haptic Feedback) при нажатии на элементы списка.

## 4. Ограничения
- Безопасность: В идеале мы должны проверять `initData` от Telegram на бэкенде. Для MVP и локальной разработки (пока мы не выкатили в прод) будем передавать `telegram_id` через query параметры или заголовки, чтобы связать фронтенд с конкретным пользователем в БД.
