# Задачи для Субагента Backend

Твоя задача — подготовить фундамент на бэкенде для Telegram Mini App.

- [ ] **Задача 1: Создание API Endpoints**
  - Создай файл `src/api/routes.py` (или добавь прямо в `main.py`).
  - Реализуй эндпоинт `GET /api/stats?user_id=123`. Возвращает JSON: общая сумма трат и массив категорий с их суммами (для графика). Используй SQLAlchemy сессию.
  - Реализуй эндпоинт `GET /api/transactions?user_id=123&limit=20`. Возвращает список последних транзакций пользователя.

- [ ] **Задача 2: Настройка CORS и Статики**
  - В `src/main.py` добавь `CORSMiddleware`, разрешив все origin (`allow_origins=["*"]`) для локальной разработки фронтенда.
  - Добавь монтирование статики: если папка `frontend/dist` существует, FastAPI должен раздавать её файлы (index.html на корневой URL `/`).

- [ ] **Задача 3: Кнопка WebApp в Боте**
  - В `src/bot/handlers.py` добавь команду `/app` (или инлайн-кнопку), которая отправляет пользователю кнопку для открытия WebApp. URL пока можно захардкодить на `https://127.0.0.1:8000` (для теста в Telegram Desktop) или использовать переменную окружения `WEBAPP_URL`.

- [ ] **Задача 4: Тесты (TDD)**
  - Напиши тесты для новых API эндпоинтов в `tests/test_api.py` с использованием `httpx` (AsyncClient).
  - Проверь всё через `flake8` и `pytest`.
