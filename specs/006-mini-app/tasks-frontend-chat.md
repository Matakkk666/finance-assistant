# Задачи для Субагента Frontend (AI Chat Tab)

Пользователь хочет добавить ИИ Чат в дашборд. 

- [x] В `App.tsx` добавь новую вкладку `'chat'` в `activeTab`.
- [x] В `TabBar` (нижнее меню) добавь третью кнопку (используй иконку `MessageCircle` или `Bot` из `lucide-react`). Сделай так, чтобы 3 кнопки смотрелись гармонично и равномерно.
- [x] Сверстай интерфейс чата (похожий на Telegram/iMessage) внутри `activeTab === 'chat'`.
- [x] Интерфейс должен содержать список сообщений (массив `{role: 'user' | 'bot', text: string}`) и поле ввода внизу с кнопкой отправки (иконка `Send`).
- [x] При отправке сообщения делай `axios.post('/api/chat', { user_id: userId, message: text })`. 
- [x] Во время ожидания ответа показывай красивый индикатор загрузки (например, прыгающие точки или надпись "Печатает...").
- [x] При получении ответа добавляй его в массив сообщений (ответ может содержать переносы строк, используй `whitespace-pre-wrap`).
- [x] Обрати внимание, чтобы список сообщений скроллился, а поле ввода было прибито к низу (но выше TabBar).
- [x] Круговая диаграмма: пользователь жаловался, что график "чуть не влезает". Пожалуйста, уменьши `outerRadius` в `PieChart` со 100 до 85-90, чтобы он точно помещался на узких экранах без обрезки!
- [x] Сделай `npm run build`.
