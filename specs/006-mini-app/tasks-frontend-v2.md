# Задачи для Субагента Frontend (UI 2.0)

Твоя задача — ПОЛНОСТЬЮ переработать дизайн React-приложения, сделав его невероятно красивым, плавным и премиальным. Пользователь просил выложиться на полную: уйти от "системного" дизайна к мягкому, современному UI в пастельных тонах.

- [x] **Задача 1: Установка библиотек и роутинг**
  - Установи иконки: `npm install lucide-react`.
  - Установи библиотеку для классов (опционально, или просто используй шаблонные строки Tailwind).
  - В `App.tsx` реализуй состояние вкладок (Главная / Операции) вместо сложного React Router. Внизу экрана всегда должен быть Bottom Navigation Bar (TabBar) с иконками.

- [x] **Задача 2: Премиальный дизайн (Пастельная тема)**
  - Обнови массив цветов `COLORS` для Recharts на красивые пастельные оттенки (лавандовый, мятный, персиковый, нежно-голубой, пудровый).
  - Используй мягкие тени (`shadow-lg`, `shadow-md`), большие скругления (`rounded-3xl` для плашек), эффект стекла (glassmorphism) где это уместно.
  - Сохрани привязку к CSS-переменным Telegram для фона, чтобы не слепить ночью, но поверх используй свои красивые элементы.

- [x] **Задача 3: Интерактивный график и Модалка**
  - На вкладке "Главная" сделай график кликабельным.
  - При клике на сегмент должна всплывать красивая модалка (снизу вверх, как Bottom Sheet) с заголовком категории и списком только тех транзакций, которые к ней относятся. Модалка должна перекрывать фон с затемнением (backdrop).

- [x] **Задача 4: Вкладка "Операции" (Продвинутая)**
  - На этой вкладке выведи полный список транзакций.
  - Добавь сверху современное поле поиска (с иконкой лупы).
  - Добавь фильтр по датам/месяцам (можно в виде симпатичных pill-кнопок). Реализуй локальную фильтрацию списка на основе поиска и выбранного фильтра.
  - Список транзакций должен быть аккуратным: иконки для категорий, красивые шрифты сумм.

- [x] **Задача 5: Сборка**
  - Обязательно выполни `npm run build` в конце и убедись, что нет ошибок TypeScript.
