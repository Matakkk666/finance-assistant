# План реализации (Feature 002: Категоризация LLM)

## Подход
Мы продолжаем использовать TDD, но с одним нюансом: запросы к реальным нейросетям — платные и медленные, а еще требуют секретного ключа (`.env`), которого нет у серверов GitHub Actions. 
Поэтому для тестов мы применим технику **Mocking (Мокирование)** — мы научим наш тест перехватывать запрос к Google Gemini и возвращать заранее заготовленный успешный ответ, не обращаясь к реальному интернету.

## Архитектура
1. **Обновление модели**: Добавим поле `category` в `Transaction`.
2. **Промпт-инжиниринг**: Напишем жесткий системный промпт, чтобы ИИ отвечал строго в формате JSON, где ключом будет ID транзакции (или её индекс), а значением — назначенная категория.
3. **LLM Сервис (`src/services/llm.py`)**: 
   - Функция будет брать пачку транзакций, превращать их в короткий текст для ИИ.
   - Использовать библиотеку `google-genai` для отправки запроса.
   - Парсить полученный от ИИ JSON и проставлять категории в объекты.
