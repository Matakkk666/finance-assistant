# Задачи для Субагента (TDD)

Твоя задача — научить `chat.py` помнить контекст переписки, чтобы уточняющие вопросы (например, "а в августе?") генерировали правильный SQL.

- [ ] **Задача 1: Структура данных для памяти**
  - В `src/services/chat.py` добавь глобальный словарь `_chat_history = {}` (или класс-обёртку). Ключ — `int` (owner_id), значение — `collections.deque(maxlen=6)` (чтобы хранить максимум 3 последних вопроса и 3 ответа).
  - Элементы истории могут быть в виде: `{"role": "user"|"bot", "content": "текст"}`.

- [ ] **Задача 2: Изменение генератора SQL**
  - Обнови функцию `generate_sql` в `src/services/chat.py`. Она должна читать `_chat_history[owner_id]`.
  - Если история есть, отформатируй её в виде текста (например, "User: ...\nBot: ...") и вставь в системный промпт для Gemini перед текущим вопросом. Это поможет LLM понять, к чему относится "на что?".

- [ ] **Задача 3: Обновление основной логики**
  - Обнови `process_user_question`. При успешной генерации финального человеческого ответа от Gemini, сохраняй пару (вопрос пользователя, финальный ответ бота) в `_chat_history[owner_id]`.
  - Если SQL-запрос не прошел валидацию (ошибка безопасности), НЕ сохраняй этот вопрос в историю, чтобы не засорять контекст.

- [ ] **Задача 4: Тесты (TDD)**
  - Обнови `tests/test_chat.py`. Добавь тест на контекст: вызови `process_user_question` с вопросом "сколько за август?", а затем "на что?". Проверь, что история в памяти (`_chat_history`) пополнилась.
  - Убедись, что `flake8` и `pytest` зеленые!
