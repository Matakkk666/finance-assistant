# План реализации (Память чата)

1. **Хранилище контекста:** В `src/services/chat.py` создать простой in-memory словарь `_chat_history = {}`, где ключ — `owner_id`, а значение — список последних сообщений (например, список словарей `[{"role": "user", "text": "..."}, {"role": "bot", "text": "..."}]`).
2. **Обновление `generate_sql`:** Изменить промпт генерации SQL в `generate_sql`. Если для `owner_id` есть история, добавлять её текст перед текущим вопросом, чтобы LLM понимала контекст.
3. **Сохранение в историю:** Обновить функцию `process_user_question`.
   - Сначала берем вопрос пользователя и генерируем SQL (с учетом истории).
   - После успешного ответа бота (генерации красивого текста), мы добавляем в `_chat_history[owner_id]` и вопрос пользователя, и финальный текстовый ответ бота.
   - Ограничивать историю последними 10 сообщениями (чтобы не раздувать промпт и не тратить токены).
4. **Тесты:** Написать тесты, симулирующие последовательные запросы к `process_user_question`, проверяя, что история сохраняется в память и очищается при превышении лимита.
