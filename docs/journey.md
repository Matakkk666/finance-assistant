## Контекст проекта

- **Идея:** персональный финансовый ассистент. Загружаю выписку из банка (CSV) → LLM раскладывает траты по категориям → дашборд → вопросы обычным языком («сколько я потратил на еду в сентябре?»).
- **Стек (предварительно):** Python + FastAPI. Окончательно выбираем на шаге 3.
- **IDE:** Antigravity.
- **Время:** 10+ часов в неделю.
- **Старт:** 2026-10-06.

### Открытые вопросы (обсудить на шагах 2–3)
- Какой банк или банки? Какой формат выписки (CSV, XLSX, PDF)?
- Приватность: финансовые данные чувствительные. Отправлять ли их во внешний LLM API, анонимизировать или использовать локальную модель?
- Интерфейс: веб-страница, Telegram-бот или оба варианта?
- Один пользователь (я) или несколько?
