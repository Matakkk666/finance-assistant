# Дорожная карта (Roadmap)

В этом документе описаны крупные этапы (Epics) реализации MVP финансового ассистента. Каждый этап будет в дальнейшем разбиваться на конкретные задачи (tasks.md).

## Этап 1: Базовая инфраструктура и Парсинг
**Цель:** Научиться принимать файл и извлекать из него данные.
- Инициализация FastAPI проекта.
- Настройка базового бота на aiogram.
- Написание логики парсинга CSV/Excel в унифицированную модель транзакций.

## Этап 2: Интеграция AI и Категоризация
**Цель:** Размечать выписку через LLM.
- Подключение API выбранной LLM (Gemini / GPT).
- Разработка системного промпта со списком пользовательских категорий.
- Логика отправки пачки транзакций в LLM и получение структурированного ответа (JSON).
- Сохранение размеченных транзакций (пока можно in-memory или SQLite).

## Этап 3: Аналитика и Чат
**Цель:** Научить бота отвечать на вопросы о деньгах.
- Сводный отчет после загрузки файла (доходы/расходы/топ категорий).
- Чат-движок: преобразование вопроса пользователя («сколько потратил на озон?») в запрос к базе транзакций (text-to-sql или передача данных в контекст LLM).
- Выдача текстового ответа пользователю в Telegram.

## Этап 4: Telegram Mini App (Дашборд)
**Цель:** Красивая визуализация подробной отчетности.
- Создание простого веб-интерфейса (HTML/CSS/JS или React).
- Эндпоинты API для отдачи агрегированных данных на дашборд (график по месяцам, круговая диаграмма категорий).
- Интеграция Mini App в интерфейс Telegram-бота.

## Этап 5: Деплой и Полировка (Закрытый релиз)
**Цель:** Запустить проект для использования семьей.
- Упаковка в Docker.
- Развертывание на сервере.
- Тестирование с реальными выписками.
