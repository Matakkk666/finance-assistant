# Автоматический Деплой

Этот скилл описывает, как агенту **самостоятельно** обновить код на сервере пользователя через SSH, не заставляя пользователя вводить команды вручную.

## Шаги для агента

1. Убедись, что текущий код закоммичен и отправлен в GitHub (`git status`, `git push`).
2. Уточни у пользователя IP-адрес сервера и имя пользователя (например, `root`), если они не указаны в контексте. (Или используй те, что пользователь даст).
3. Используй инструмент `run_command`, чтобы выполнить SSH-команду прямо из локального терминала пользователя. 
   
   *Команда, которую нужно выполнить (в одну строку):*
   ```powershell
   ssh -i $env:USERPROFILE\.ssh\minter_vps_ed25519 -o IdentitiesOnly=yes root@194.58.41.95 "cd /root/finance-assistant && git checkout -- . && git pull origin master && source venv/bin/activate && pip install -r requirements.txt && ./restart.sh"
   ```
4. Скрипт `restart.sh` убьет старого бота и uvicorn, подождет 3 секунды (чтобы Телеграм успел разорвать старое соединение) и надежно запустит бота и FastAPI в фоне, избегая `TelegramConflictError`.
5. Проверь успешность выполнения команды и сообщи пользователю, что бот обновлен!
