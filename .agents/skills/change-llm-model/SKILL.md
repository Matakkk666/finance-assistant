# Смена LLM модели

Когда нужно переключиться на новую модель Gemini (например, при устаревании старой версии), действуй так:

1. Открой файл `src/services/llm.py`.
2. В функции `categorize_transactions` найди вызов `client.models.generate_content`.
3. Замени значение параметра `model` (например, с `gemini-3.8-flash` на ту, что указал пользователь).
4. Обязательно запусти локальные тесты: `venv\Scripts\pytest.exe`, чтобы убедиться, что синтаксис запроса не сломался.
5. Предупреди пользователя, что новая модель может иначе понимать контекст или стоить других денег.
