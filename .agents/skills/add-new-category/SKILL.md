# Добавление новой категории

Если пользователь просит добавить новую категорию для финансов, выполни следующие шаги строго по порядку:

1. Открой файл `src/services/llm.py`.
2. Найди список `CATEGORIES` в начале файла.
3. Аккуратно добавь новую категорию в этот список. 
4. Сохрани файл и запусти `venv\Scripts\flake8.exe src` для проверки PEP8.
5. Объясни пользователю, что парсер и аналитика подхватят эту категорию автоматически (т.к. аналитика просто группирует всё, что выдаст ИИ), а нейросеть начнет её использовать при следующем запуске.
