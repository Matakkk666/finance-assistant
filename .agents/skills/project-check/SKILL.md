# Скилл: Проверка всего проекта (Code Review & Testing)

Этот скилл предназначен для полного прогона тестов и проверок качества кода (линтеров) во всем проекте.

## Инструкция

1. **Проверка Backend (Python)**
   - Выполни команду для прогона линтера `flake8`:
     ```bash
     flake8 src tests
     ```
   - Если линтер нашел ошибки форматирования, предложи пользователю исправить их (или исправь сам через `autopep8` / `isort`).
   - Выполни команду для запуска тестов `pytest`:
     ```bash
     pytest -v
     ```
   - Убедись, что все тесты зеленые. Если есть упавшие тесты (Red), проанализируй их и напиши план починки.

2. **Проверка Frontend (React/TypeScript)**
   - Перейди в папку фронтенда и прогони сборку, чтобы TypeScript проверил все типы:
     ```bash
     cd frontend && npm run build
     ```
   - Проверь отсутствие ошибок компиляции (TS errors).

3. **Отчет**
   - Напиши пользователю красивый отчет о статусе проекта:
     - 🛡️ Линтеры (пройдены/ошибки)
     - 🧪 Тесты (пройдено X, упало Y)
     - 🌐 Фронтенд сборка (успех/ошибка)
   - Если всё идеально, поздравь пользователя с качественным кодом! 🚀
