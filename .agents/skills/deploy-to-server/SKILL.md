# Инструкция по деплою (Deploy)

Поскольку мы пока не настроили CI/CD автодеплой (это будет на Шаге 9), деплой происходит в ручном полуавтоматическом режиме. 

Когда пользователь просит задеплоить код, выдай ему этот список команд, чтобы он выполнил их в консоли **своего VPS-сервера** (НЕ выполняй это локально!):

1. **Подключиться к серверу** (через SSH):
   `ssh user@твоя-ip-адрес`

2. **Перейти в папку проекта**:
   `cd /path/to/finance-assistant` (путь зависит от того, где клонирован проект на сервере)

3. **Стянуть свежий код из GitHub**:
   `git pull origin master`

4. **Обновить зависимости** (если они менялись):
   `source venv/bin/activate`
   `pip install -r requirements.txt`

5. **Перезапустить бота**:
   - Если бот работает через `systemd`: `sudo systemctl restart finance-bot`
   - Если бот работает через `tmux` или `screen`, нужно зайти в сессию, остановить старого (Ctrl+C) и запустить `python -m src.bot.main`

*Примечание для ИИ*: Всегда напоминай пользователю проверять файл `.env` на сервере, так как он не переносится через Git.
